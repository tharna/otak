# otak

Otak is the Android companion app for [Segoy](https://github.com/tharna/segoy): capture ideas, answer questions, approve plans and pull requests, and follow the pipeline from your phone. Native Kotlin and Jetpack Compose, no backend; it talks to GitHub with your own token.

Status: not started. The app is built through the Segoy pipeline in thin slices (O1–O6); see the Segoy repo's `docs/otak-app-spec.md`.
